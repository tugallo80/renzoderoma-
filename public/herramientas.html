Automatización de escritorio
Rubik Agent
Agente IA que controla el mouse y teclado de tu PC. Ejecuta tareas en Vectorworks, navegadores y cualquier programa de Windows usando lenguaje natural.
Windows Python 3.x Gratis para usuarios Rubik
agent.py requirements.txt Instrucciones

Instalación rápida

1
Instalá Python si no lo tenés: python.org/downloads Marcá "Add Python to PATH" al instalar.
2
Descargá los dos archivos de arriba y ponelos en la misma carpeta.
3
Abrí CMD en esa carpeta y ejecutá: pip install -r requirements.txt
4
Ejecutá el agente: python agent.py Se abre una ventana flotante. Ingresá tu email y contraseña de rubikbolivia.com y listo.
